## 🔐 О проекте

Модуль шифрования — курсовая работа по разработке комплексного решения для защиты данных с использованием шифра Цезаря. Проект включает реализацию трёх пользовательских интерфейсов: консольного, веб-интерфейса на Flask и графического интерфейса на tkinter.

## ✨ Возможности

* **Многоплатформенность**: поддержка трёх интерфейсов для разных категорий пользователей
* **Шифрование данных**: реализация алгоритма Цезаря с поддержкой:
    * кириллицы
    * латиницы
    * специальных символов
* **Веб-сервис**: REST API с поддержкой:
    * JSON-формата
    * HTML-ответов
    * системы логирования
* **GUI-приложение**: оконный интерфейс с функциями:
    * загрузки/сохранения файлов
    * шифрования/дешифрования
    * управления данными

## 🛠 Технологический стек

* **Язык разработки**: Python 3.x
* **Веб-фреймворк**: Flask
* **GUI**: tkinter
* **Библиотеки**:
    * logging для логирования
    * csv для работы с файлами
    * json для работы с данными
    * os для файловых операций
