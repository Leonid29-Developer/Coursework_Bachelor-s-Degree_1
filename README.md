Десктопное приложение для управления записью на занятия в студии спортивных бальных танцев. Учебный коммерческий проект, разработанный на C# (WinForms) с базой данных SQL Server.

> **Примечание:** Этот проект — одна из ступеней в моём развитии как разработчика. Он зафиксирован в текущем состоянии как точка роста, а не как пример production-готового кода.

---

## Возможности

### Для пользователя
- Регистрация и авторизация в системе
- Просмотр расписания занятий на две недели вперёд
- Бронирование и отмена записи на занятие
- Отображение только тех занятий, которые соответствуют возрастной группе пользователя
- Визуальная индикация свободных и занятых мест

### Для администратора
- Назначение типа танца (Танго, Румба, Самба, Джайв, Пасодобль, Фокстрот, Вальс, Ча-Ча-Ча) для конкретного слота расписания
- Управление расписанием: добавление и удаление занятий

## Архитектура

Приложение построено по клиент-серверной схеме:

- **Клиент** — WinForms-приложение с многооконным интерфейсом (авторизация, регистрация, главное окно расписания, панель администратора).
- **Сервер** — SQL Server. Взаимодействие осуществляется через хранимые процедуры (аутентификация, регистрация, бронирование, управление расписанием).

### Используемые хранимые процедуры

- `Authentication` — вход пользователя
- `Registration` — создание нового пользователя
- `CheckingAvailabilityLogin` — проверка уникальности логина
- `Get AgeGroup ID` — получение возрастной группы пользователя
- `Get Lesson > TypeDancing` — получение данных о занятии
- `Get Lesson > Index` — поиск ID занятия по дате и времени
- `Get CountRecords` — подсчёт занятых мест
- `Add RecordReservation` / `Remove RecordReservation` — бронирование и отмена
- `Add Lesson` / `Remove Lesson` / `Update Lesson > TypeDancing` — управление расписанием
- `Get AgeGroup From ClassSchedule` — получение возрастной группы для слота

## Запуск

### Требования

- Windows 10/11
- .NET Framework 4.8
- Microsoft SQL Server (Express или выше)
- Visual Studio 2022 (для сборки из исходников)

### Шаги

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Leonid29-Developer/SportsBallroom_DancingStudio.git
   ```

2. **Настройте базу данных:**

   Подключите файл `.mdf` из папки `SQL/` к вашему экземпляру SQL Server через SQL Server Management Studio или Visual Studio.

3. **Настройте строку подключения:**

   В исходном коде (`Forms/*.cs`) найдите строку подключения:

   ```csharp
   Data Source='';Integrated Security=True
   ```

   Укажите имя вашего SQL Server вместо пустых кавычек, например:

   ```csharp
   Data Source=.\SQLEXPRESS;Integrated Security=True
   ```

4. **Соберите и запустите:**

   Откройте `SportsBallroom_DancingStudio.sln` в Visual Studio и нажмите `F5`.
